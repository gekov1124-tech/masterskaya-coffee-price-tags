# Мастерская Кофе — редактор ценников

Отдельный репозиторий проекта редактора ценников.

## Текущая версия

`editor-v26.html`

В v26:
- можно вставить сразу несколько строк вида `Название, цена`;
- для каждой распознанной строки создаётся отдельный ценник;
- дубликаты уже существующих названий не создаются;
- повторы внутри вставленного списка тоже пропускаются;
- разделы полностью убраны;
- название, описание и цена остаются редактируемыми;
- размер названия можно увеличить до 300%;
- все названия сохраняют единый фактический размер;
- цена редактируется, перемещается и меняет размер;
- сохранены горизонтальный, вертикальный и компактный режимы;
- сохранены копирование, удаление, сортировка, импорт, экспорт, печать и настройки оформления.

GitHub Pages публикует `editor-v26.html` как главную страницу сайта.
