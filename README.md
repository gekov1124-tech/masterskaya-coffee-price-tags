# Мастерская Кофе — редактор ценников

Отдельный приватный репозиторий проекта редактора ценников.

## Текущая версия

`editor-v24.html`

В v24:
- новый ценник создаётся из одной строки вида `Круассан малина, 259`;
- программа сама подбирает категорию;
- для известных товаров автоматически подставляет сохранённое описание;
- для неизвестной позиции использует категорию `ПРОЧЕЕ` и оставляет описание пустым;
- кнопка `Пустой ценник` сохраняет прежний ручной способ создания;
- ползунок размера названия изменяет все наименования;
- все названия сохраняют единый фактический размер;
- длинные названия переносятся на дополнительные строки;
- описание автоматически сдвигается и не обрезается;
- цена редактируется, перемещается и меняет размер;
- сохранены горизонтальный, вертикальный и компактный режимы;
- сохранены копирование, удаление, сортировка, импорт, экспорт, печать и настройки оформления.
