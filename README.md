# Мастерская Кофе — редактор ценников

Отдельный приватный репозиторий проекта редактора ценников.

## Текущая версия

`editor-v22.html`

В v22:
- наименования товаров имеют единый визуальный размер;
- длинные названия переносятся на дополнительные строки;
- описание автоматически сдвигается и не обрезается;
- цена редактируется, перемещается и меняет размер;
- сохранены горизонтальный, вертикальный и компактный режимы;
- сохранены добавление, копирование, удаление, сортировка, импорт, экспорт, печать и настройки оформления.
