# Мастерская Кофе — редактор ценников

Отдельный репозиторий проекта редактора ценников.

## Текущая версия

`editor-v27.html`

В v27:
- размер названия регулируется до 500%;
- крупные буквы больше не должны обрезаться по высоте или ширине;
- программа измеряет реальную высоту текста, переносы и ручное смещение каждого блока;
- все названия сохраняют единый фактический размер;
- можно вставить сразу несколько строк вида `Название, цена`;
- дубликаты существующих названий и повторы внутри списка не создаются;
- разделы полностью убраны;
- название, описание и цена редактируются и перемещаются;
- сохранены горизонтальный, вертикальный и компактный режимы;
- сохранены копирование, удаление, сортировка, импорт, экспорт, печать и настройки оформления.

GitHub Pages публикует `editor-v27.html` как главную страницу сайта.
